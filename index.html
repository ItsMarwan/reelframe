    Settings

    Personalize how Reelframe works for you.

    Personalized recommendations
    Adds a "For You" row above your videos and photos, built from the categories and titles you engage with most.
    Continue watching & Recently added
    Shows the "Continue watching" and "Recently added" rows above your video grid.
    Website background
    Upload your own photo or reuse one from your library, then apply a full-site wallpaper effect.
    “I came” cooldown (hours)
    How long before the same photo can be used again. Use 0 for no cooldown, or 0.5 for 30 minutes.
    Show cum on photos
    Each “I came” press lands cum on the photo, and it stays there. Turn this off to hide it.
    Preferred cum area
    Choose a body part, a custom zone, or let it fire anywhere.
    Ropes per press
    How many separate ropes are shot one after another each time (1–12).
    Randomize rope count
    Vary the number of ropes a little on every press instead of always using the exact number above.
    Amount - 100%
    How much liquid is in each rope: thicker, longer streams.
    Cum size - 100%
    How big each mark is when it lands on the photo. Applies to new presses.
    Dripping - 70%
    How many drips run down from each mark, and how long they get (0 = none). Applies to new presses.
    Reset cum look
    Puts ropes, amount, size and dripping back to their defaults.
    Clean cum
    Removes the cum marks from all saved “I came” photos.
    Mini player
    Keep a video playing in a small floating window when you leave Watch. Turn this off to just pause instead.
    Real mini player (Picture-in-Picture)
    Uses your browser's native floating window instead of Reelframe's built-in one — it can float outside the browser entirely.
    Auto-approve share connections
    Controls whether an incoming share (via code or QR) starts sending right away, or waits for you to approve it. "Local network only" and "Internet only" are a best-effort guess based on how the other device connected.
    Lock on blur
    Automatically hide Reelframe and require a password when the window loses focus.
    Lock password
    Set or change the password that unlocks Reelframe when blurred.
    Auto-lock after inactivity
    Lock Reelframe automatically after this many minutes without any activity. 0 disables this.
    Lock delay after losing focus
    Wait this many seconds after the window loses focus before locking. 0 locks instantly.
    Library backup
    Export or import your saved favorites and Watch Later list as a JSON file.
    NSFW content detection BETA
    Scans your photos and flags any that may contain NSFW content. NSFW detection is available without a beta code.
    Scan status
    NSFW detection is enabled by default.
    Region detection BETA
    A second, optional pass that finds the exact flagged spots in a photo so only those areas get blurred instead of the whole image. Runs in the background — safe to pause and resume, even across a reload.
    Region scan status
    Region detection is available without a beta code.
    Scan on startup
    Automatically scan any new or changed photos each time you open Reelframe, instead of only when you press the button above.
    Hide flagged media
    When on, flagged photos and videos show a warning badge and stay hidden until you tap to unblur them. When off, scan results are kept, but nothing is blurred or tagged.
    Scan media scope
    Choose whether to scan all media, only photos, or only video thumbnails.
    Focus blur method
    Pick how the focus view hides flagged photos: normal blur, pixelate, or black box.
    What counts as NSFW?
    Choose which whole-image labels and exposed-body classes should trigger a flag.
    Redeem a code
    Legacy code field; NSFW detection no longer requires a beta key.
